Par où on reprend (couche métier)

Socle IA + référentiels + matching/reco + auth = faits. On enchaîne sur la couche métier qui alimente les parcours ci-dessus. Tables déjà créées (vides) → services/schemas/controllers + tests pytest + données de démo étiquetées.

  1. Profil (fondation) — CRUD + aspirations/poste visé + extraction de compétences depuis un CV (symétrique du poste) + personas de démo. Alimente Mon profil, base de connaissance, matching.
  2. Offre — dérive d'une Fiche, types poste/mission/projet/mentorat, cycle de vie (brouillon→validation RH→ouvert→clôture), poussée manager/RH. Alimente marketplace + publication.
  3. Candidature — postuler = matching persisté (score + écarts + snapshot), statut, décision humaine. + matching inverse (candidats internes d'une offre) pour « profils compatibles » / hauts potentiels.
  4. Souhaits d'évolution — workflow collab → manager (accorder/transmettre) → RH.
  5. Dashboards RH data-driven — cartographie en direct + ponctuelle, alertes/actions, veille entretiens (agrégations).
  6. Assistants IA — coach & entretiens branchés sur un vrai LLM local (ancrage sur profil/données), garde-fous.
